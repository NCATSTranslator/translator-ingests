# Koza Maps

Local folder of Koza mapping files pre-generated by suitable scripts.

## HMDB 'cellular_locations' names to Gene Ontology Cellular Compartment terms

The [go_cellular_map.py](../../../../docs/scripts/koza_maps/go_cellular_map.py) script generates the contents of the 
[go_lookup.csv](./go_lookup.csv) file.

## HMDB 'biospecimen_locations' or 'tissue_locations' names to UBERON terms

The [go_cellular_map.py](../../../../docs/scripts/koza_maps/uberon_map.py) script generates the contents of the 
[uberon_lookup.csv](./uberon_lookup.csv) file.
