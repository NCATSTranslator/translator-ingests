## Implemented: SIGNOR compound identifiers and absent context

SIGNOR emits `CID:` identifiers for PubChem compounds. The transform previously
passed them directly into chemical nodes and their edge endpoints. It now expands
only `CID:` to `PUBCHEM.COMPOUND:` on every existing chemical construction path.
It preserves already canonical identifiers, ChEBI identifiers, PubChem substance
identifiers, category routing, evidence, and edge ordering.

The configured RENCI snapshot contains 244 distinct CIDs across 463 endpoint
occurrences. A live Node Normalizer query returned **0/244** matches for the raw
identifiers and **237/244** for their canonical compound identifiers. Among the
240 distinct CIDs on currently supported category/effect routes, **233** resolve
after the change. These are identifier measurements, not a full normalized
production-graph run. Seven canonical identifiers still have no match; they are
listed in [the evidence summary](signor-evidence-2026-09-21.json).

Example: `CID:24795070` does not resolve; `PUBCHEM.COMPOUND:24795070` resolves to
`CHEBI:95061`, SGI-1776. Node Normalizer:
<https://nodenormalization-sri.renci.org/docs>.

The functional tests also reproduced an absent-context failure: pandas grouping
converts `None` in `CELL_DATA`/`TISSUE_DATA` to `NaN`, after which the transform
attempts `.split()` on a float. Preparation now restores missing values in those
two columns to `None`. Tests cover absent and present contexts, all nine
protein/chemical/small-molecule routing combinations (including the three
existing exclusions), both edge endpoints, and evidence preservation. Excluded
routes remain excluded; expanding their scientific scope is a separate decision.

`SID:` is deliberately unchanged. A checked substance example,
`SID:134445687`, failed normalization both as written and as
`PUBCHEM.SUBSTANCE:134445687`; substituting a compound prefix would change its
meaning. The configured snapshot contains no raw `NCBIGene:` endpoint IDs, so
that historical entry in [#383](https://github.com/NCATSTranslator/translator-ingests/issues/383)
requires investigation of normalized output rather than an assumed prefix fix.

## SIGNOR acquisition: the endpoints work; migration is still needed

Both of these requests completed successfully on the investigation date:

```sh
curl -fL -o stable.tsv -D stable.headers \
  https://signor.uniroma2.it/releases/getLatestRelease.php
curl -fL -o complete.tsv -D complete.headers \
  --data 'organism=human&format=csv&submit=Download' \
  https://signor.uniroma2.it/download_entity.php
```

The form parameters come from the official
[downloads page](https://signor.uniroma2.it/downloads.php).

| Data source | Rows | Columns | Confidence score | Direct flags |
| --- | ---: | ---: | --- | --- |
| Configured RENCI snapshot | 42,190 | 28 | Present | YES / NO / UNK |
| Latest stable release (`Jul2026_release.txt`) | 43,315 | 27 | Absent | t / f / empty |
| Current form export, organism=human | 43,677 | 28 | Present | YES / NO / UNK |

The stable endpoint returns its version in `Content-Disposition`. Despite the
human form selection, the exported `TAX_ID` values include other organisms;
that field should not be assumed to equal the entity-selection filter. Counts
and SHA-256 hashes are recorded in the evidence summary. The configured mirror
is <https://stars.renci.org/var/data_services/signor/all_data_27_02_26.tsv>.

The installed downloader uses GET and has no form-body option. Replacing the URL
with the stable endpoint alone would omit required `SCORE` data and change the
meaning of the direct flag. A complete migration for
[#303](https://github.com/NCATSTranslator/translator-ingests/issues/303) needs:

1. A choice between the scored current export and the stable release.
2. POST support (or a source-specific download adapter) for the current export.
3. A version strategy tied to the selected content; a mutable form export must
   not be labeled as the stable release merely because the release page says July.
4. Schema, flag, confidence, and organism-policy checks before replacing the mirror.
