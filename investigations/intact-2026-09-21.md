## Evidence loss reproduced; merging already exists

The real transform was exercised on the current public
[EBI-10379036 MITAB record](https://www.ebi.ac.uk/Tools/webservices/psicquic/intact/webservices/current/search/query/EBI-10379036?format=tab27&firstResult=0&maxResults=10).
The record has an IntAct miscore of **0.67** and detection method **MI:0397**.
Its emitted edge retains the PMID and `infores:intact` provenance but neither
score nor detection method. See the captured source fields and emitted edge in
[intact-evidence-2026-09-21.json](intact-evidence-2026-09-21.json).

Code inspection confirms `sourceDatabase` is never used by the transform:
`INTACT_SOURCES` is fixed. The guide's claim that imported supporting sources are
preserved is therefore not implemented in the current transform. The example
itself reports IntAct as its source; it does not establish the frequency of
missing external supporting sources in the full dataset.

A separate experiment exercised the actual `merge_single` pipeline with two
constructed edges derived from that output: equal endpoints/predicate/source,
publications `PMID:1` and `PMID:2`, and differing proposed scores 0.2 and 0.9.
The merger produced one edge with both publications, kept **0.2**, and reported
`has_confidence_score` as a dropped conflicting property. The constructed scores
and PMIDs are test inputs, not claims about the source record.

Consequences for [#245](https://github.com/NCATSTranslator/translator-ingests/issues/245):

- Duplicate merging and publication union already exist downstream; a second
  source-specific merger should not be added without a distinct need.
- The merge key uses endpoints, predicate, primary source, and qualifiers. Since
  several IntAct interaction types map to one predicate and the original type is
  not emitted, it does not necessarily preserve separate original interaction types.
- Biolink 4.4.4 exposes scalar `has_confidence_score`, but conflicting values need
  an explicit preservation/aggregation policy before enabling it.
- The guide's proposed `supporting_method_types` field does not exist on the pinned
  association model. Select a supported representation for detection methods.
- Map actual source-database PSI-MI identifiers to registered infores entries,
  preserve contributing sources, and test their union after merging.

No IntAct semantic change is included in this branch. The existing Entrez fix
remains in #523; the other historical normalization failures have not all been
remeasured against a full IntAct release.

## Investigation environment and limits

The source-record transform and constructed conflict experiment used Python
3.12.11, Biolink Model 4.4.4, BMT 1.5.0, Koza 2.4.0, and ORION 1.3.3. They used
real Koza and pipeline merger implementations, without mocks. This was a single
source-record check and a controlled merger experiment, not a full IntAct release
or an estimate of evidence-loss frequency across the source.
